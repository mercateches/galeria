# 📸 Galería de Fotografías

## 📝 Descripción

Este proyecto consiste en el desarrollo de una galería de fotografías utilizando HTML y CSS, como parte de las actividades prácticas del bootcamp de **Soy Henry**.

El objetivo es poner en práctica los fundamentos de CSS, la organización de elementos mediante CSS Grid y Flexbox, y la creación de diseños adaptables a diferentes tamaños de pantalla.

## 🚀 Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** estilos, colores, tipografía y presentación visual.
- **CSS Grid:** distribución de las tarjetas de fotografías en filas y columnas.
- **Flexbox:** alineación y organización de los elementos del encabezado.
- **Media Queries:** adaptación del diseño a dispositivos móviles y tablets.
- **Variables CSS y HSL:** gestión de colores y consistencia visual.

## ✨ Características

- Galería organizada en tres columnas en pantallas grandes.
- Diseño adaptable a tablets con dos columnas.
- Diseño para móviles con una sola columna.
- Tarjetas con imágenes, títulos y descripciones.
- Efectos visuales al pasar el cursor sobre las tarjetas.
- Esquinas redondeadas y sombras para mejorar la presentación.
- Uso de variables CSS reutilizables para colores y espaciados.

## 📱 Diseño responsive

El diseño se adapta a distintos tamaños de pantalla mediante media queries:

| Dispositivo | Distribución |
|---|---|
| Escritorio | 3 columnas |
| Tablet | 2 columnas |
| Móvil | 1 columna |

## 🧠 Aprendizajes

Durante el desarrollo de este proyecto se practican los siguientes conceptos:

- Uso de selectores y propiedades CSS.
- Aplicación de un reset básico y `box-sizing: border-box`.
- Uso de unidades relativas como `rem`.
- Definición de variables CSS.
- Comprensión del modelo de color HSL.
- Diferencias y aplicaciones de CSS Grid y Flexbox.
- Implementación de efectos `hover` y transiciones.
- Creación de diseños responsive con media queries.
- Control de versiones y publicación del proyecto en GitHub.

## ▶️ Cómo visualizar el proyecto

1. Clona este repositorio o descarga sus archivos.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre el archivo `index.html` en tu navegador.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para visualizar los cambios mientras desarrollas.
